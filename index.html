GEX.

A 2D and 3D game engine. Build levels in a tab per blueprint, write game logic as events in .jlb, and press Play.

Download for Windows Source code One .exe, no installer. Docs, templates and a demo game are built in.

01What's in it

Everything a small game needs, in one program that starts in a second and idles quietly.

Blueprints

A blueprint is a tree of objects. Any object can be an instance of another blueprint with overrides on top, so editing the enemy updates every enemy.

2D

Sprites and sprite-sheet animation, text, cameras, trigger areas, physics bodies, tilemaps with automatic collision and A* pathfinding.

3D

Shapes and models (glTF with skeletal animation, OBJ), lights with shadows, sky, fog, physics and mesh collision.

The editor

Move, rotate and scale tools, undo, a debugger with breakpoints, a profiler, an animation timeline, Vim keys if you want them, and live values while the game runs.

Display

Pick a resolution and how it scales: fit with bars, stretch, whole-number pixel scaling, or expand. Full screen fills any screen.

Export

File → Export game makes a folder for Windows, Linux or macOS, with your name and icon on it.

UI, sound, input

Panels, buttons, text inputs and bars anchored to the screen; sound effects and music; keyboard, mouse and gamepads with named input actions.

Particles and tweens

Sparks, smoke and trails previewed live in the editor, and any property slid over time with one command.

Multiplayer

One player hosts, the others join. Shared objects stay in step between everyone's games, and events cross over: HOST_GAME, JOIN_GAME, NET_SPAWN, NET_EMIT.

Work together

Share a project and work on it at the same time: blueprints and scripts stay in step as you edit, and you see each other's tabs, pointers, selections and text cursors.

Half-Life 2 assets

Textures, models, maps and sounds read straight from your own Steam install. Never copied into exports.

02Scripting in .jlb

Scripts are written in .jlb, a small language with ALL-CAPS commands and plain names. Events are just functions with fixed names.

coin_collide
>> Coin: picked up when something touches it.

DEF on_collide_start(other) {
    IF NAME_OF(other) == "Player" {
        GLOBAL.score += 1
        SET("Score", "text", "Score: " + GLOBAL.score)
        TWEEN(NULL, "scale_x", 0, 0.2, "back")
        DESTROY(NULL)
    }
}
  • A script's variables belong to its object, and the object's own properties are plain names: x, speed, visible.
  • Events: on_create, on_step(dt), on_collide_start, on_press_space, timers, buttons, and your own.
  • Every command has a full page with an example in the built-in Commands reference (F1).
  • Scripts reload while the game runs. Set a breakpoint, step line by line, watch values.
  • Change graphics, physics, display and key bindings from a script, for an options menu.

032D and 3D in one editor

The same tabs, tools and scripts for both. Play runs the game right in the view.

04Get started

Windows 10 or 11 with a graphics card that runs DirectX 12 or Vulkan.

  1. Download GEX.zip and unzip it anywhere.
  2. Run GEX.exe. The project library opens. From then on GEX updates itself when it starts.
  3. Open the demo game, or start a new project from a template.
  4. Follow Tutorial 1: objects, scripts, collisions, a score, a menu, export.

On Linux or macOS, build it from source with Rust 1.85 or newer:

git clone https://github.com/ASDFboy/gex
cd gex
cargo run --release -p gex-editor
